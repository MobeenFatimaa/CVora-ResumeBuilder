# Overview

CVora is a modern AI-powered resume builder designed to help students, professionals, and job seekers create clean, ATS-friendly resumes through an intuitive web interface.

The application provides real-time resume editing, multiple professional templates, local data storage, theme customization, and high-quality PDF export, allowing users to build professional resumes without requiring an online account or database.

# Installation

Clone the repository

```bash
git clone https://github.com/yourusername/CVora.git
```

Navigate to the project

```bash
cd CVora/frontend
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```
